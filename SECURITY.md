# Security Policy

## Scope

RogueGuard is a local synthetic cybersecurity learning project. It does not connect to or modify real cloud identities or resources.

## Safe-use requirements

- Use synthetic data only.
- Test locally or within an explicitly assigned and approved training sandbox.
- Do not test college production systems, third-party systems, or accounts you do not own or have explicit permission to assess.
- Never commit credentials, access tokens, private keys, personal data, or unredacted sensitive logs.
- Do not interpret simulated containment as actual cloud containment.

## Reporting a vulnerability

Please do not publish sensitive vulnerability details in a public issue. Contact the repository maintainer privately through the contact method listed on the GitHub profile. Include a concise description, affected file or component, reproduction steps using synthetic data, and potential impact.

Please allow reasonable time for investigation and remediation before public disclosure.

## Security claims

A passing test suite is evidence only for the test cases executed. It is not a security certification, penetration-test result, or proof of production readiness.
